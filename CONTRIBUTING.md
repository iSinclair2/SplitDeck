# Contributing to SplitDeck

Thanks for helping improve SplitDeck.

1. Use macOS 14 or later and a current version of Xcode.
2. Open `Package.swift` in Xcode, or build with `./scripts/build-app.sh`.
3. Keep changes native to macOS and avoid adding sign-in requirements or analytics.
4. Explain any new permission, private API, network request, or persistent data in the pull request and README.
5. Test light and dark appearances, narrow and full-screen windows, all three tile sizes, and banner layouts.

When reporting a bug, include the macOS version, media source, widget size, appearance settings, and a screenshot or short screen recording when useful.
